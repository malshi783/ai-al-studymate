# 🎓 AI A/L StudyMate
### AI-Powered Study & Workload Management Mobile Application

AI A/L StudyMate is a mobile application designed to help Sri Lankan Advanced Level (A/L) students organise their academic activities, manage study workloads and improve their learning experience.

The application aims to provide students with a centralised platform to manage school activities, tuition classes, assignments, revision schedules and examinations while exploring AI-powered personalised study assistance.

**Project Type:** Personal Project  
**Platform:** Android & iOS  
**Development Status:** In Progress

---

## 🎯 Project Objectives

- Help Sri Lankan A/L students organise their academic activities.
- Simplify study schedule and workload management.
- Help students keep track of assignments and deadlines.
- Organise tuition classes and examination schedules.
- Support effective revision planning.
- Explore AI-powered personalised study recommendations.

## ⚙️ Getting Started

### Prerequisites

Install the following:

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android Emulator or a physical Android device
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/malshi783/ai-al-studymate.git
```

### 2. Navigate to the Project

```bash
cd ai-al-studymate
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Check Flutter Configuration

```bash
flutter doctor
```

### 5. Run the Application

```bash
flutter run
```
